# Практикум «Случайность в играх» (C#, Jupyter)

Тетрадка `rng_practicum_student.ipynb` запускается прямо в браузере через GitHub Codespaces — ничего устанавливать на компьютер не нужно.

## Как начать

1. Войдите в свой аккаунт GitHub (если аккаунта нет — зарегистрируйтесь на github.com, это бесплатно).
2. На странице этого репозитория нажмите зелёную кнопку **Code** → вкладка **Codespaces** → **Create codespace on main**.
3. Подождите. **Первый запуск занимает 3–5 минут**: в облаке собирается среда с .NET 9 и Jupyter. Повторные запуски — несколько секунд.
4. Откроется VS Code в браузере, а в нём — тетрадка. Если она не открылась сама, щёлкните по `rng_practicum_student.ipynb` в списке файлов слева.
5. Справа вверху нажмите **Select Kernel** → **Jupyter Kernel** → **.NET (C#)**.
6. Выполните первую ячейку (`Shift + Enter`). Должно появиться «Готово.».

## Важно

- Бесплатно даётся 60 часов работы в месяц на каждого. Когда закончили — закройте вкладку: среда сама остановится через 30 минут бездействия. Остановить сразу можно на странице github.com/codespaces (… → **Stop codespace**).
- Ваши изменения сохраняются в вашем codespace между запусками. Чтобы вернуться к работе, откройте github.com/codespaces и выберите свой codespace, а не создавайте новый.
- Неиспользуемый codespace удаляется автоматически примерно через месяц. Готовую тетрадку скачайте: правый клик по файлу → **Download**.
